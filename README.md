# PERCEPT Preprocessing Pipeline

## Overview:
This PERCEPT pipeline includes preprocessing, MELD, CINEMA_OT, and CellChat used in the study.

### Preprocessing
This preprocessing pipeline is used to do the quality control, sample integration and clustering for scRNA-seq data starting from the "filtered_bc_feature_matrix" data provided by CellRanger.

#### Preprocessing Structure:
- Part_1: create Seurat object from filtered_feature_bc_matrix generated by CellRanger
- Part_2: visualizations to check sample quality and decide QC cutoffs
- Part_3: filtering based on QC cutoffs and further advanced methods (doublet finder) to get final singlets
- Part_4: clustering and cell type labeling
    - Adjust the resolution for clustering
    - Then do cell type labeling using DEGs, SingleR, VISION, etc.
    - Visualize using cell type using density plot

#### How to run the preprocessing pipeline
- one .Rmd file, one .R file that contains the functions used in the .Rmd file.
    - Preprocessing_part_1:
        - Input: filtered_feature_bc_matrix
        - Output: Seurat object of all cells
    - Preprocessing_part_2:
        - Input: Seurat object of all cells
        - Output: visulizations
    - Preprocessing_part_3:
        - Input: Seurat object of all cells, custom QC cutoffs
        - Output: Seurat object of filtered singlets
    - Preprocessing_part_4:
        - Input: Seurat object of filtered singlets
        - Output: clustered Seurat object 

### CellChat
- Step 1: Run "CellChat_MDK.Rmd" for each sample
- Step 2: Run "CellChat_MDK_comparison.Rmd" for the comparisons you want.
